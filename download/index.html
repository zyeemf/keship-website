导入命令

Windows PowerShell 
wsl --import KeShip E:\WSLDistros\KeShip <镜像所在路径>\KeShip-WSL-Image.tar --version 2

导入失败先核对文件完整性（与发放方提供的校验值比对）；.tar 不完整是导入失败最常见的原因。

i此页如何启用下载

镜像（约 11 GB）不放在网站目录（超出托管限额）。编辑本目录下的 mirror-status.json：把对应线路的 ready 改为 true、url 填下载地址，并更新 sha256——推送后本页自动出现可点击按钮，无需改动任何代码。

i本地打开时检测不生效

就绪检测需要经由 HTTP 访问网页（如站点服务器）；直接双击打开本文件时按钮保持“尚未提供”状态，以服务器访问为准。
